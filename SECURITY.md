# Security policy

## Supported versions

Only the latest release is supported.  `ddd gui`, the browser interface, is still a
preview within it: see [its security page](docs/gui_security.rst) for what it defends
against, what it trusts instead, and what it leaves open.

## Reporting a vulnerability

Report it privately, through this repository's **Security** tab and its **Report a
vulnerability** button, rather than in a public issue.

A report should hold:

* the version affected;
* the steps that reproduce it;
* what an attacker gains by it.

There is no promised response time.
